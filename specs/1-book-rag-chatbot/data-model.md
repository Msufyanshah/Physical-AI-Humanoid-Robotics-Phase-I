# Data Model: AI/Spec-Driven Technical Book + Integrated RAG Chatbot

**Feature**: 1-book-rag-chatbot
**Date**: 2025-12-10
**Status**: Draft

## Overview

This document defines the data models for the Physical AI & Humanoid Robotics technical book with integrated RAG chatbot. It details the entities, their attributes, relationships, and validation rules based on the feature specification.

## Core Entities

### Book Module
- **Description**: Represents one of the four main topics (ROS 2, Gazebo, Isaac Sim, VLA) with associated content, exercises, and examples
- **Attributes**:
  - id: string (unique identifier)
  - title: string (e.g., "The Robotic Nervous System (ROS 2)")
  - description: string (brief overview)
  - order: integer (sequence number)
  - learning_objectives: array of strings
  - summary: string
  - checklist: array of strings
  - word_count: integer (between 2000-3750 to meet total requirement)
- **Relationships**:
  - Has many: Chapter
- **Validation Rules**:
  - Title is required and must be 5-100 characters
  - Order must be between 1-4
  - Learning objectives must be present (at least 1)
  - Checklist must be present (at least 1)
  - Word count must be between 2000-3750

### Chapter
- **Description**: A sub-section of a module containing learning objectives, content, summary, and checklist
- **Attributes**:
  - id: string (unique identifier)
  - module_id: string (foreign key to Book Module)
  - title: string
  - content: string (Markdown content)
  - order: integer (sequence number within module)
  - learning_objectives: array of strings
  - summary: string
  - checklist: array of strings
  - word_count: integer
- **Relationships**:
  - Belongs to: Book Module
  - Has many: Exercise
  - Has many: CodeExample
- **Validation Rules**:
  - Title is required
  - Module ID is required and must reference an existing module
  - Content must be in valid Markdown format
  - Learning objectives, summary, and checklist are required
  - Order must be positive

### User
- **Description**: A registered user who can access personalized content and features
- **Attributes**:
  - id: string (unique identifier)
  - email: string (unique)
  - username: string (optional, unique if provided)
  - password_hash: string (encrypted)
  - role: string (enum: "student", "developer", "educator", "admin")
  - background: string (e.g., "beginner", "intermediate", "advanced")
  - hardware_level: string (e.g., "simulator-only", "basic-hardware", "advanced-hardware")
  - preferred_language: string (default: "en", also supports "ur")
  - created_at: timestamp
  - updated_at: timestamp
- **Relationships**:
  - Has many: Question
  - Has many: PersonalizationSettings
  - Has many: ChatLog
- **Validation Rules**:
  - Email is required and must be valid email format
  - Email must be unique
  - Role must be one of the specified enum values
  - Background must be one of: "beginner", "intermediate", "advanced"

### Question
- **Description**: A query submitted to the RAG chatbot about book content
- **Attributes**:
  - id: string (unique identifier)
  - user_id: string (foreign key to User, optional for anonymous questions)
  - question_text: string
  - question_type: string (enum: "general", "selected_text")
  - selected_text: string (optional, for selected text questions)
  - book_section_id: string (optional, to track which section user was reading)
  - created_at: timestamp
- **Relationships**:
  - Belongs to: User (optional)
  - Belongs to: Book Section (optional)
  - Has one: Answer
- **Validation Rules**:
  - Question text is required and between 5-1000 characters
  - Question type must be one of the specified enum values
  - If question type is "selected_text", then selected_text is required

### Answer
- **Description**: A response generated by the RAG chatbot based on book content
- **Attributes**:
  - id: string (unique identifier)
  - question_id: string (foreign key to Question)
  - answer_text: string
  - source_chunks: array of strings (IDs of content chunks used)
  - confidence_score: float (0.0-1.0)
  - generated_at: timestamp
- **Relationships**:
  - Belongs to: Question
- **Validation Rules**:
  - Answer text is required
  - Confidence score must be between 0.0 and 1.0
  - Source chunks must reference valid book content chunks

### Code Example
- **Description**: A reproducible code block with specific version requirements
- **Attributes**:
  - id: string (unique identifier)
  - chapter_id: string (foreign key to Chapter)
  - title: string
  - code: string (the actual code content)
  - language: string (e.g., "python", "bash", "yaml", "xml")
  - version_requirements: string (e.g., "ROS 2 Humble", "Python 3.8+")
  - execution_notes: string (how to run the code)
  - expected_output: string (what the code should produce)
- **Relationships**:
  - Belongs to: Chapter
- **Validation Rules**:
  - Title and code are required
  - Language must be a valid programming/markup language
  - Chapter ID must reference an existing chapter

### Exercise
- **Description**: Hands-on exercise associated with a chapter
- **Attributes**:
  - id: string (unique identifier)
  - chapter_id: string (foreign key to Chapter)
  - title: string
  - description: string
  - difficulty: string (enum: "beginner", "intermediate", "advanced")
  - instructions: string
  - solution: string
  - hints: array of strings
- **Relationships**:
  - Belongs to: Chapter
- **Validation Rules**:
  - Title, description, and instructions are required
  - Difficulty must be one of the specified enum values
  - Chapter ID must reference an existing chapter

### Chat Log
- **Description**: Log of user interactions with the RAG chatbot
- **Attributes**:
  - id: string (unique identifier)
  - user_id: string (foreign key to User, optional for anonymous)
  - question_id: string (foreign key to Question)
  - answer_id: string (foreign key to Answer)
  - timestamp: timestamp
  - session_id: string (to group related questions)
- **Relationships**:
  - Belongs to: User (optional)
  - Belongs to: Question
  - Belongs to: Answer
- **Validation Rules**:
  - Question ID and Answer ID are required
  - Timestamp is required

### Personalization Settings
- **Description**: User-specific settings that affect content delivery
- **Attributes**:
  - id: string (unique identifier)
  - user_id: string (foreign key to User)
  - preferred_hardware_examples: string (enum: "simulator", "real_hardware", "both")
  - experience_level: string (enum: "beginner", "intermediate", "advanced")
  - favorite_topics: array of strings
  - learning_pace: string (enum: "slow", "normal", "fast")
  - notification_preferences: object (email, push, etc.)
- **Relationships**:
  - Belongs to: User
- **Validation Rules**:
  - User ID is required and must reference an existing user
  - Experience level must be one of the specified enum values
  - Learning pace must be one of the specified enum values

### Image/Media
- **Description**: Visual content with proper attribution information
- **Attributes**:
  - id: string (unique identifier)
  - chapter_id: string (foreign key to Chapter)
  - filename: string
  - title: string
  - alt_text: string
  - attribution: string (source information)
  - license: string (e.g., "CC BY", "AI-generated", etc.)
  - usage_notes: string (where and how the image should be used)
- **Relationships**:
  - Belongs to: Chapter
- **Validation Rules**:
  - Filename, title, and attribution are required
  - License must be properly specified
  - Chapter ID must reference an existing chapter
